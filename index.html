Personal product · PWA · in production

Aula Dining

367 active users Live app ↗

Digitises daily dining and feast management for the residents of Ahsanullah Hall North, BUET: meal scheduling, seat booking in batches, coupon-based attendance and a live workflow for mess staff.

  • Rules in the database. Postgres constraints, triggers and SQL functions enforce every rule across 59 versioned migrations. Clients never write tables directly.
  • Safe under load. Ordered row locks and idempotency keys mean booking never oversells, and retries or double taps are harmless.
  • Three roles. Student, mess manager and super admin, with every function checking the caller's role.
  • Tested and load-tested. 18 database integration test files run on real Postgres in WASM (PGlite). The live deployment passed a load test.
  • Next.js
  • TypeScript
  • Supabase
  • PostgreSQL
  • pg_cron
  • Web Push
  • Vitest

Audio Craft

An interactive audio signal processing and visualisation toolkit with a clean dashboard: FFT spectrum, spectrograms, Butterworth filtering and noise reduction. It also does vocal separation with Demucs and lyric transcription with Whisper. The Android build (Signal Lab) is native Kotlin and Compose and runs the models on the phone, offline.
